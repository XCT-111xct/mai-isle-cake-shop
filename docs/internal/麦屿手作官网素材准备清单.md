## 二、风格统一规范（所有图片必须遵守）

| 项 | 值 |
|----|----|
| 品牌主色 | 暖米白 `#F8F3EA` / 卡其棕 `#8B6F52` / 奶油金 `#F0E1B9` / 深棕 `#6B5238` |
| 整体氛围 | 温暖、手作、高级感；烘焙房暖光；奶油和面粉的柔和质感 |
| 摄影风格 | 美食摄影 / 品牌摄影，浅景深，自然光，无杂乱背景 |

| 色调方向 | 暖色调（米白/棕/金为主），饱和度适中，不过度滤镜 |

> 生成时所有 prompt 开头统一加："Warm bakery brand photography style, cream and khaki brown color palette (#F8F3EA, #8B6F52, #F0E1B9), soft natural light, premium artisan bakery feel"

## 三、A. LOGO 图形标（1 张）

### A1. 麦屿手作品牌图形标
- **用途**：导航栏 logoMark（当前是文字 "M" 圆标，替换为品牌图形标）；页脚品牌区
- **尺寸**：1024×1024，透明背景 PNG（生成时 background=transparent）
- **Prompt（生成时使用）**：
  ```
  极简风格的蛋糕店品牌 LOGO 图形标，圆形徽章造型：
  - 中央是一个抽象的小岛（屿）造型，岛上有麦穗（麦）元素，二者融合成蛋糕形象
  - 外围细圆环装饰，线条干净，无文字
  - 配色：卡其棕 #8B6F52 主色 + 奶油金 #F0E1B9 点缀，白底/透明底
  - 扁平矢量风格（flat vector），适合缩小到 48px 仍清晰
  品牌含义：麦 = 面粉谷物（烘焙起点），屿 = 静谧小岛（专注打磨甜品的角落）
  ```
- **替换位置**：`apps/web/src/components/Navbar.tsx` 第 68 行 `logoMark`（当前为文本 "M"）→ 换成 `<img src={logoUrl}>`

## 七、执行流程（AI 生成时按此顺序）

1. **先出小样**：生成 B5 草莓奶油蛋糕 + A1 LOGO 两张，给老大确认风格
2. **批量蛋糕图**：B1–B10 逐款生成（每张独立调用，确保一一对应）
3. **品牌配图**：C1–C3（竖版）
4. **门店图**：D1–D3（横版）
5. **替换**：
   - 蛋糕图 / 门店图 → 后台管理系统上传（写回数据库 `image_url`）
   - LOGO / 品牌配图 → 直接改前端文件引用
6. **验证**：前台截图 蛋糕展示页 / 关于麦屿页 / 门店信息页 / 导航栏 LOGO，确认全部生效

## 八、注意事项

1. **费用**：17 张 × 约 5–10 credits/张 ≈ 85–170 credits（生成前已与老大确认）
2. **生成失败重试**：个别图不满意（风格/内容不对）→ 调整 prompt 单独重生成，不整批重跑
3. **版权**：AI 生成的图用于官网运营无版权风险，但需确保不含他人品牌元素（已写入风格规范禁用项）
4. **尺寸统一**：蛋糕图 1024×1024、门店图 1024×768、品牌图 1024×1280、LOGO 1024×1024 透明底
5. **备份**：替换前先备份数据库（数据库文件复制一份），避免误操作
